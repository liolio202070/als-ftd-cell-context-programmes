# License selection required before public release

No license has been applied in this draft because reuse rights are an author decision and author/declaration work is intentionally deferred.

Recommended structure, subject to institutional and source-data obligations:

- Code in `scripts/`: MIT or BSD-3-Clause.
- Author-generated figure Source Data, compact supplementary tables, documentation and figures: CC BY 4.0.
- Third-party raw data: excluded from this repository and governed by the originating repositories.
- Manuscript text: follow the journal/publisher agreement; do not automatically apply a software license.

Before publishing, the authors should confirm the choices, add the corresponding license text(s), identify any files that require a different notice, and record the decision in the Zenodo metadata.
